# 项目概览

论文题目：基于特征约束生成模型的主轴振动信号数据扩充方法。

论文类型：中文工程技术类小论文初稿。

研究对象：主轴空载振动信号，使用 `X-2` 通道数据。

写作目标：围绕传统加噪扩充、VAE 残差扩充、普通 WGAN-GP 和残差特征约束 WGAN-GP 进行方法比较，形成可继续补充文献和图表编号的 Markdown 正文。

输出文件：`paper.md`。正文使用 UTF-8 编码，一级标题使用 `#`，二级标题使用 `##`，三级标题使用 `###`，公式使用 LaTeX 格式。

引用策略：暂不生成参考文献列表，所有需要引用的位置统一使用 `【引用：作者 年份，主题】` 占位。
